# F1 Paddock

Учебный многостраничный сайт о Формуле-1: Live Timing, команды, пилоты, календарь,
зачёт, телеметрия, радио и история. Написан на чистых HTML, CSS и JavaScript,
без сборщиков и фреймворков. Единственная внешняя библиотека — Chart.js
(подключается с CDN на странице «Телеметрия»).

Все данные на сайте демонстрационные.

## Запуск

Сайт нужно открывать через локальный сервер: через `file://` браузер блокирует
`fetch` (не загрузятся пилоты из JSON и данные Live Timing).

Из папки `f1_dash`:

```
python3 -m http.server 8000 --bind 127.0.0.1
```

Адрес: http://127.0.0.1:8000/frontend/index.html

Подойдёт и любой другой статический сервер, например Live Server в VS Code.

## Скрипты

### `modal.js` — окно «Связаться» (все страницы)

Добавляет в шапку кнопку «Связаться» и создаёт окно `<dialog>` с формой: имя
и фамилия, группа, email, телефон. Поля проверяются регулярными выражениями.
Данные никуда не отправляются — показывается только сообщение об ошибке или
успехе. Окно закрывается крестиком, клавишей Esc или кликом по тёмному фону.

### `about.js` — форма контактов («О проекте»)

Та же проверка, что в `modal.js`, но для формы прямо на странице. Телефон можно
вводить с пробелами, скобками и дефисами — перед проверкой они убираются.

> Регулярные выражения продублированы в `about.js` и `modal.js`. Если меняются
> правила проверки, править нужно оба файла.

### `drivers.js` — пилоты (list и detail)

- Загружает `assets/data/drivers.json` через `fetch`.
- `list(items)` — рисует карточки всех пилотов в сетку.
- `detail(id)` — показывает подробности одного пилота в окне `<dialog id="driverModal">`.
- Карточки — это кнопки, поэтому открываются и мышью, и с клавиатуры (Enter).

### `telemetry.js` — графики

Два графика Chart.js: линейный (скорость двух пилотов по дистанции круга)
и столбчатый (время трёх секторов).

### Скрипт Live Timing (внутри `live.html`)

Настройки — в объекте `CFG` в начале скрипта:

- `API` — адрес сервера, по умолчанию `http://localhost:8080/api`;
- `POLL_MS` — как часто опрашивать сервер (2000 мс);
- `MOCK_FALLBACK` — если сервер не отвечает, показывать демонстрационную гонку.

Сервер должен отдавать JSON по четырём адресам: `/session`, `/standings`,
`/track`, `/positions`. Точный формат ответов описан в комментарии в начале
скрипта.

### `home.js` — обгоны в Live-таблице на главной

Описан ниже, в разделе «Анимации».

### `live-example.js`

Упрощённый пример таблицы Live Timing для API `/api/live`. Ни к одной странице

## Анимации на главной

Все три находятся в первом экране главной страницы. Файлы: `frontend/index.html`,
`assets/css/home.css`, `assets/js/home.js`.

Общая шкала времени после загрузки страницы:

```
0.2 с ─ трасса начинает прорисовываться
0.3 с ─ загорается 1-й огонь, дальше по одному каждые 0.3 с
1.5 с ─ горят все 5 огней
2.0 с ─ трасса прорисована полностью
2.2 с ─ огни гаснут разом; болид стартует
2.25 с ─ выезжает 1-я строка заголовка, через 0.12 с — 2-я
3.0 с ─ первый обгон в Live-таблице, дальше каждые 3 с
```

### 1. Стартовые огни и появление заголовка (CSS)

Пять огней, как на старте гонки: загораются по одному, затем гаснут все
одновременно — и строки заголовка «Почувствуй каждый круг.» выезжают снизу
из-под маски.

- Каждому огню в разметке задан номер `style="--i:0"` … `--i:4`.
- Огонь горит, только пока идёт его анимация `light-on`. Задержка
  `0.3s + 0.3s·i` — когда загореться, длительность `1.9s − 0.3s·i` — сколько
  гореть. У всех огней задержка + длительность = 2.2 с, поэтому гаснут они
  в один момент.
- Каждая строка заголовка обёрнута в `.h1-line` с `overflow: hidden` — это
  маска. Внутренний `<span>` анимацией `line-up` поднимается снизу
  (`translateY(135%)` с наклоном `skewY`) на своё место.
- `padding-block` / `margin-block` у маски расширяют видимую область, чтобы
  не обрезались выступающие части букв (кратка у «Й», хвосты у «Д»).

### 2. Болид на схеме трассы (SVG)

Схема трассы справа сначала прорисовывается линией, затем по ней в цикле едет
светящийся болид со шлейфом.

- Прорисовка — CSS: у линии трассы `pathLength="1"`, `stroke-dasharray: 1`,
  а анимация `track-draw` уменьшает `stroke-dashoffset` с 1 до 0.
- Движение — SVG-анимация `<animateMotion>` по тому же пути
  (`<mpath href="#heroTrack">`). `rotate="auto"` поворачивает болид
  по направлению трассы, `calcMode="spline"` даёт разгон и торможение.
- Шлейф — три круга с той же траекторией, но стартом позже на 0.05, 0.1
  и 0.15 с. На прямых болид быстрее, поэтому шлейф там длиннее.
- `<animate attributeName="opacity">` плавно показывает болид в начале круга
  и прячет его в конце, чтобы не было видно скачка от финиша к старту.

### 3. Обгоны в Live-таблице (JavaScript, FLIP)

Каждые 3 секунды пилот на P2 или P3 обгоняет соперника впереди. Строки плавно
меняются местами, обгоняющий подсвечивается зелёным, номера позиций
и отставания обновляются.

Плавная перестановка сделана по технике FLIP:

1. **First** — запоминаем `offsetTop` каждой строки.
2. **Last** — переставляем строку в DOM (`before()`), обновляем позиции.
3. **Invert** — считаем, насколько каждая строка сдвинулась.
4. **Play** — через Web Animations API (`element.animate()`) строка начинает
   со старого места и плавно приезжает на новое.

`offsetTop` используется вместо `getBoundingClientRect()`, потому что панель
повёрнута в 3D (`perspective` + `rotateY`), а `offsetTop` этот поворот
не учитывает.

### Режим «уменьшить движение»

Если в системе включено «Уменьшить движение» (`prefers-reduced-motion`),
огни и заголовок сразу показываются в конечном виде, трасса нарисована
целиком, болид скрыт, а `home.js` не запускает обгоны.

## Ограничения

- Данные на всех страницах — примеры, а не реальная статистика.
- Формы контактов только проверяют поля и ничего не отправляют.
- Сервер на C++ в репозиторий не входит (`backend/` пуст). Без него Live Timing
  показывает демонстрационную гонку.
